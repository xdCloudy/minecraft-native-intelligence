# Scaling

The scaling target is many persistent agents sharing expensive foundation computation without merging their lives. Separate hot runtime state, durable per-agent state, shared immutable model weights, and optional small personal modules.

Candidate techniques include dynamic batching, key/value-cache policy research, priority queues, asynchronous planning, low-frequency cognition for sleeping/distant agents, hierarchical simulation detail, accelerated headless worlds, and distributed model serving. Optimisations must not give low-frequency agents hidden knowledge or skip consequences that alter fairness.

Measure agents per accelerator/server, tick and decision latency percentiles, throughput, memory per agent, save/load time, queue fairness, degradation under load, and behavioural quality versus compute. Scaling claims must include world complexity and cognition cadence.
