# Grounded Language

Chat belongs inside the perception–memory–planning–action loop. A message is an event from another being with identity, time, place, relationship context, and uncertain content; speaking is a world action with recipients and consequences.

The same fundamental pathway should handle human-to-agent and agent-to-agent conversation. Language should refer to current surroundings and remembered events, update beliefs with provenance, support questions and teaching, coordinate joint activity, and change later action appropriately. A fluent detached chatbot is not success.

Evaluate grounded reference, instruction-versus-autonomous-goal arbitration, delayed conversational recall, truth checking against experience, clarification, deception/error robustness, joint-task coordination, and causal influence on behaviour. Keep the internal ontology Minecraft-native while maintaining external disclosure to humans and operators.
