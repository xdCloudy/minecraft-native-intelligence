# Personality

Personality is a persistent pattern in how an agent evaluates options, explores, socialises, accepts risk, organises, cooperates, and allocates attention. It is not a prose prompt or a fixed class such as “builder.”

Candidate mechanisms include slowly changing latent state, experience-conditioned preferences, value/goal priors, habit statistics, and compact personal modules. Any representation must permit initially similar agents to diverge through experience while remaining behaviourally measurable and administratively inspectable.

Experiments should test cross-situation consistency, experience-driven change, stability across save/load, distinctness between agents, resistance to prompt-only mimicry, and whether effects persist when language output is removed. Avoid hardcoded stereotypes and avoid treating one behaviour as a psychological diagnosis.
